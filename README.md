# Anki Telegram Bot — Portfolio

Telegram-Bot zum Erstellen von Anki-Lernkarten aus Texten und Fotos. Die KI erstellt einen Entwurf; Nutzer prüfen und bearbeiten ihn vor dem Speichern.

Technologien: Python, python-telegram-bot, Pydantic, SQLite, HTTP APIs, AnkiConnect, Docker Compose und pytest.

Das Projekt wurde mit KI-Unterstützung (Codex) entwickelt. Mein Beitrag: Anforderungen und Abläufe definieren, Code lesen, Funktionen testen und Fehlerkorrekturen steuern.

Diese öffentliche Portfolio-Kopie enthält einen bereinigten Stand mit neuer Git-Historie. Benutzer-IDs, Decknamen und Serveradressen in Beispielen sind fiktiv. Persönliche Daten, Zugangsdaten und Produktions-Deployment sind nicht enthalten. Sprach- und Audioeingabe ist derzeit deaktiviert.

Für die Einrichtung: `.env.example` kopieren, die fiktiven Benutzer-IDs durch eigene IDs ersetzen und eigene API-Zugangsdaten eintragen. Die russische Dokumentation folgt unten; die CI führt nur Tests aus. Hinweise zum eigenen Deployment: [docs/DEPLOY.md](docs/DEPLOY.md).

# Telegram-Бот Для Anki-Карточек По Немецкому

Проект помогает быстро превращать слова, фразы и предметы из реальной жизни в полезные Anki-карточки для изучения немецкого языка.

Идея проста: пользователь отправляет Telegram-боту русское слово, немецкое слово, фразу или фотографию предмета, а бот готовит карточку с немецким вариантом, русским переводом, простым примером, грамматикой, оценкой частотности и изображением.

Главная цель проекта - собирать не просто отдельные переводы, а готовый usable German: слова, словосочетания и фразы, которые можно применять в быту, на работе и при подготовке к DTB B2.

## Что Умеет Бот

- Принимать русские слова и фразы.
- Принимать немецкие слова и фразы.
- Принимать фотографии предметов и ситуаций и создавать карточку по фото.
- Обработка голосовых сообщений и MP3-аудиофайлов временно отключена: код сохранен для будущей переделки, но бот сейчас не принимает audio/voice как вход для карточек.
- Создавать черновик Anki-карточки с переводом, примером и полезными пометками.
- Всегда прикреплять изображение к карточке.
- Показывать превью перед добавлением в Anki.
- Давать возможность исправить карточку перед сохранением.

## Пользовательский Сценарий

Пользователь отправляет боту, например:

- `страховка`
- `die Versicherung`
- `оформить страховку`
- `einen Termin vereinbaren`
- `Как сказать официанту "без сдачи"`
- фото предмета

Бот определяет возможные значения и сначала просит выбрать конкретный смысл. Например, для `Essen` он может предложить `das Essen / еда` и `essen / есть`. Если пользователь спрашивает, как сказать что-то в ситуации, бот извлекает смысл для карточки: для `Как сказать официанту "без сдачи"` исходным смыслом станет `без сдачи`, а варианты будут естественными немецкими фразами. В каждом варианте бот показывает, что именно будет добавлено как target карточки, чтобы отличать голый глагол от словосочетания или фразы. После выбора значения бот готовит карточку и картинку.

Пример:

```text
eine Versicherung abschließen
оформить / заключить страховку

Пример:
Ich möchte eine Versicherung abschließen.

Частотность: средняя
```

Если пользователь отправил фотографию, бот использует ее как изображение карточки и делает карточку формата "как это называется по-немецки?". Если к фото есть caption, он учитывается как подсказка.

Обработка голосовых сообщений и MP3-аудиофайлов сейчас выключена на уровне Telegram handlers. Код скачивания, транскрибации и сохранения `UserAudio` оставлен в проекте, чтобы позже переделать сценарий без потери заготовки.

Перед сохранением бот показывает превью. Пользователь может:

- добавить карточку в Anki;
- попросить ИИ исправить карточку по свободной инструкции;
- запросить другую картинку;
- отменить добавление.

После добавления бот показывает Note ID и полную известную стоимость запросов Polza, использованных для карточки:

```text
Добавлено в Anki. Note ID: 1700000000000. Стоимость: 4,45 руб.
```

В сумму входят выбор значения, генерация и повторы, генерация изображения и последующие ИИ-исправления. Если Polza не вернула цену хотя бы для одного успешного ответа, бот показывает известную нижнюю границу как `Стоимость: не менее 4,45 руб.`; если цен нет совсем — `Стоимость: недоступна`.

## Что Содержит Карточка

Каждая карточка должна включать:

- немецкое слово, словосочетание или фразу;
- немецкий пример с выделенным целевым словом;
- русский перевод;
- перевод примера на русский;
- значение, синонимы, грамматику, стиль или тематику, если это полезно;
- частотность;
- изображение;
- при необходимости - короткую грамматическую подсказку.

Актуальный Anki note type проекта - `German Context v1`. Полная спецификация полей и шаблонов описана в [docs/ANKI_CARD_FORMAT.md](docs/ANKI_CARD_FORMAT.md). Старый шаблон `n8n v.2` используется только как исторический источник формата; при запуске бот автоматически исправляет в нем устаревший немецкий TTS-тег.

Изображение обязательно для каждой карточки:

- если пользователь прислал фото, используется это фото;
- если фото нет, бот генерирует изображение через `polza.ai` без предварительного поиска в Wikimedia.

Для будущей переработки аудио-сценария в коде оставлена поддержка `ffmpeg`, Polza STT и поля `UserAudio`, но сейчас эти Telegram handlers не зарегистрированы.

Генерация изображения поддерживает синхронный ответ с готовым URL и async-ответ `requestId` с последующим polling media status.

## Принципы Проекта

- Карточка не добавляется в Anki автоматически без подтверждения.
- Сначала пользователь выбирает конкретное значение, затем бот показывает полный preview и пользователь решает, сохранить карточку или исправить ее.
- Примеры должны быть простыми и практичными, ориентировочно уровня A2-B1.
- Бот должен помогать учить живые фразы, а не только отдельные словарные единицы.
- Частотность сохраняется в карточке как отдельное поле.
- Изображение должно помогать запоминанию и не должно подсказывать ответ текстом на самой картинке.

## MVP

Первая версия должна поддерживать:

- отдельные слова;
- словосочетания;
- простые фразы;
- фотографии предметов;
- голосовые сообщения с сохранением пользовательского аудио в карточке;
- генерацию черновика карточки;
- обязательное превью;
- корректировку перед добавлением;
- сохранение готовой карточки в Anki.

В MVP не нужно углубляться в сложные сценарии синхронизации, внутренние статусы, детальную серверную архитектуру или низкоуровневую интеграцию с Anki. Главное - быстрый и удобный путь от слова, фразы или фото до проверенной карточки.

Текущий технический MVP описан в [docs/MVP.md](docs/MVP.md). Первый этап фокусируется на текстовых словах и фразах, локальном запуске рядом с Anki Desktop и генерации изображения через `polza.ai`.

## Роль polza.ai

`polza.ai` рассматривается как основной ИИ-сервис проекта. Он должен использоваться для обработки пользовательского ввода, генерации содержимого карточек и, при необходимости, работы с изображениями.

Окончательное решение по изображениям можно принять позже: бот может искать подходящие картинки, генерировать их через ИИ или сочетать оба подхода. Важное продуктовое требование остается неизменным: каждая карточка должна быть визуальной.

## Запуск В Docker

Docker Compose запускает два сервиса:

- `bot` - Telegram-бот;
- `anki-desktop` - Anki Desktop с AnkiConnect и веб-интерфейсом.

Перед запуском создайте `.env` из `.env.example` и заполните как минимум:

```env
TELEGRAM_BOT_TOKEN=...
POLZA_AI_API_KEY=...
ALLOWED_TELEGRAM_USER_IDS=100000001
```

Сборка и запуск:

```powershell
docker compose up -d --build
```

Anki Desktop доступен только локально по адресу:

```text
http://localhost:3000
```

При самом первом запуске Anki Launcher может попросить нажать Enter после установки runtime. Затем выберите язык интерфейса. Для синхронизации нажмите `Синхронизация` в Anki и один раз войдите в AnkiWeb. Авторизация и коллекция сохраняются в постоянном Docker volume.

Бот проверяет наличие авторизации перед синхронизацией и в Docker-образе вызывает расширенный AnkiConnect action `syncAndWait`, который ждёт завершения AnkiWeb collection sync. Если вход не выполнен, карточка останется в локальной коллекции Anki, а в логах появится `anki.add_card.sync_error` с сообщением `AnkiWeb login required`. После входа нажмите `Синхронизация` ещё раз, чтобы отправить уже добавленные локальные карточки в AnkiWeb.

Основные команды:

```powershell
docker compose ps
docker compose logs -f bot
docker compose logs -f anki-desktop
docker compose restart
docker compose down
```

Данные сохраняются в volumes:

- `anki-data` - профиль, коллекция, медиа и авторизация Anki;
- `bot-data` - локальная база и медиа бота;
- `bot-logs` - логи бота.

Команда `docker compose down` не удаляет данные. Не используйте флаг `-v`, если не хотите удалить коллекцию Anki и локальную базу бота.
