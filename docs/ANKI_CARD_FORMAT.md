# Формат Anki-Карточки: German Context v1

Актуальный note type проекта: `German Context v1`.

Для английского профиля бот аналогично поддерживает note type `English Context v1`. Он использует тот же набор совместимых полей и две карточки, но английский текст, английский TTS и английские подсказки в шаблоне. Внутренние имена `SentenceDE` и связанных полей сохранены ради совместимости со старыми черновиками SQLite.

Для корейского профиля используется `Korean Context v1` с корейским TTS (`ko_KR`) и корейскими грамматическими подсказками. В корейском режиме `SentenceDE` содержит только изучаемое корейское слово или выражение, а `SentenceRU` — только его русский перевод; предложения-примеры не генерируются. Серверный Anki включает `espeak-ng`, чтобы встроенная озвучка работала в Linux-окружении. Язык карточки хранится в черновике отдельно, поэтому смена текущего языка пользователя не меняет уже созданные черновики.

Он создан как копия хорошего шаблона `n8n v.2`, но с нейтральным именем, потому что `n8n` больше не является частью проекта. Новые карточки должны создаваться в `German Context v1`. Если в коллекции еще есть исторический `n8n v.2`, бот при запуске заменяет в его шаблонах устаревший немецкий TTS-тег на явный голос, совместимый с текущим немецким шаблоном.

## Поля

| Поле | Назначение |
| --- | --- |
| `SentenceDE` | Простое немецкое предложение A2-B1 с целевым словом или фразой в `<b>...</b>`. |
| `Word` | Целевое немецкое слово, словосочетание или фраза без артикля. |
| `Article` | Артикль `der`, `die`, `das` или пустая строка для глаголов, фраз и слов без артикля. |
| `GenderColor` | CSS-класс рода: `m`, `f`, `n` или пустая строка. |
| `Level` | Уровень CEFR, например `A1`, `A2`, `B1`, `B2`. |
| `TranslationRU` | Основной русский перевод. |
| `SentenceRU` | Русский перевод предложения с целевым переводом в `<b>...</b>`. |
| `Image` | HTML изображения вида `<img src="filename.png">`. |
| `MeaningRU` | Точное объяснение выбранного значения на русском без смешивания с другими значениями. |
| `OtherMeaningsRU` | До 2-4 важных других значений с пометами употребления в HTML-списке; пусто для однозначного слова. |
| `DefinitionRU` | Legacy-имя поля: по содержанию здесь короткое немецкое определение выбранного значения. |
| `Synonyms` | До 4-6 надёжных немецких синонимов в HTML-списке с кратким русским пояснением различий; может быть пустым. |
| `GrammarTable` | Структурированные формы, управление, конструкции, 3-5 коллокаций и релевантная частая ошибка. |
| `VerbForms` | Для одиночного глагола: `Infinitiv / Präteritum / Perfekt`, например `vereinbaren / vereinbarte / hat vereinbart`; пусто для остальных типов. |
| `Etymology` | Обязательное русское пояснение происхождения, состава слова и развития значения либо явная отметка неопределённости. |
| `StyleAndGroup` | Регистр, тематика, региональность и ограничения употребления на русском. |
| `ImageQuery` | Поисковый запрос для изображения, 1-4 слова на немецком или английском. |
| `FrequencyBand` | Частотность: `very_common`, `common`, `medium`, `rare` или `special`. |
| `SourceText` | Исходный пользовательский ввод, из которого была создана карточка. |
| `UserAudio` | Пользовательское голосовое сообщение в формате Anki media, например `[sound:telegram_voice_123.mp3]`. |

## HTML

Разрешенный минимум HTML:

- `<b>...</b>` для выделения целевого слова или фразы в `SentenceDE` и `SentenceRU`;
- `<ul><li>...</li></ul>` для списков значений;
- `<table><tr><td>...</td></tr></table>` для грамматики;
- `<img src="...">` только в поле `Image`.
- `[sound:filename.mp3]` только в поле `UserAudio`.

Не нужно добавлять текст на изображение: картинка должна помогать вспомнить смысл, но не подсказывать ответ буквами.

`SentenceDE` и его перевод `SentenceRU` образуют единственный полный пример в карточке. В справочных полях допустимы короткие формы, конструкции и коллокации, но не дополнительные предложения-примеры.

Грамматическое наполнение зависит от единицы:

- существительное: род, Genitiv, Plural и управление;
- глагол: управление, основные формы, отделяемость и возвратность;
- прилагательное: степени сравнения и управление;
- служебное слово: функция, позиция и порядок слов;
- фраза или коллокация: структура, управление и вариативные части.

Для одиночного глагола генератор дополнительно заполняет `VerbForms`. На обороте карточки оно показывается рядом с крупным словом через `/`. Для фраз и коллокаций, даже если внутри есть глагол, `VerbForms` остается пустым.

Перед сохранением генератор проверяет минимальную содержательность грамматики и этимологии, формат пояснённых синонимов и других значений, а также отсутствие неподдерживаемых HTML-тегов. Некорректный результат запускает стандартную повторную генерацию.

Перед проверкой генератор локально очищает частые безопасные HTML-отклонения модели: убирает `<i>`, `<em>`, `<span>` и `<font>`, заменяет `<strong>` на `<b>`, заменяет `<br>` пробелом и удаляет атрибуты у разрешённых тегов. Это не расширяет формат карточки: структурные или потенциально опасные теги по-прежнему считаются ошибкой.

Источник изображения сохраняется тегом карточки: `wikimedia`, `polza_generated`, `telegram_photo` или `no_image`.

## Карточки

`German Context v1` содержит две карточки:

- `Карточка 1`: немецкое предложение и изображение на лицевой стороне, подробности на обороте.
- `Карточка 2`: русское предложение и изображение на лицевой стороне, немецкое предложение и подробности на обороте.

В `Карточка 2` лицевая сторона зависит от `SentenceRU`, чтобы не создавать карточку с пустым фронтом при отсутствии русского предложения.

`UserAudio` показывается на обороте обеих карточек отдельным блоком "Голос пользователя". Это аудио не заменяет встроенный TTS для немецкого предложения: шаблон использует `{{tts de_DE voices=com.google.android.tts-de-de-x-dea-local:SentenceDE}}`, а `UserAudio` хранит исходный голосовой ввод пользователя. Голосовые сообщения сохраняются в Anki media как MP3 для лучшей совместимости с AnkiWeb и мобильными клиентами.

## Совместимость

В коде старые поля черновика сохраняются как fallback:

- `word_or_phrase_de` соответствует `Word`;
- `example_de` соответствует `SentenceDE`;
- `example_ru` соответствует `SentenceRU`;
- `grammar_note_ru` соответствует `GrammarTable`.
- `frequency_band` соответствует `FrequencyBand`;
- `source_text` соответствует `SourceText`.
- `audio_path` соответствует `UserAudio` после сохранения MP3 в Anki media.

Это нужно только для совместимости со старыми черновиками и тестами. Новая генерация должна заполнять поля `German Context v1`.
