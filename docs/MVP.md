# MVP: Telegram-Бот Для Anki

Этот MVP запускается локально на ПК рядом с Anki Desktop и AnkiConnect. Он проверяет главный текстовый сценарий: пользователь отправляет слово или фразу, бот готовит карточку с картинкой, показывает превью и после подтверждения добавляет карточку в Anki.

## Входит В MVP

- Русские и немецкие слова.
- Русские и немецкие фразы.
- Фото предметов и ситуаций: бот распознает главный объект или действие и создает карточку по изображению.
- Голосовые сообщения и MP3-аудиофайлы временно отключены на уровне Telegram handlers; код аудио-пайплайна сохранен для будущей переделки.
- Генерация содержимого карточки через `polza.ai`.
- Генерация изображения через `polza.ai` без предварительного поиска в Wikimedia.
- Выбор конкретного значения через inline-кнопки перед генерацией полной карточки и поиском картинки.
- Превью карточки в Telegram.
- Быстрые действия: добавить, AI-исправить, другая картинка, отмена.
- Сохранение черновиков в SQLite.
- Добавление подтвержденной карточки в Anki через AnkiConnect.
- Запуск AnkiWeb-синхронизации через AnkiConnect после успешного добавления карточки.

VPS, Anki Sync Server и экспорт `.apkg` не входят в первый этап.

## Запуск

1. Установить Python 3.11+.
2. Установить Anki Desktop и аддон AnkiConnect.
3. Создать Telegram-бота и получить `TELEGRAM_BOT_TOKEN`.
4. Получить API-ключ `polza.ai`.
5. Создать `.env` на основе `.env.example`.
6. Указать в `.env` разрешенного пользователя и текущие модели:

```dotenv
ALLOWED_TELEGRAM_USER_IDS=100000001
# Для семейного режима можно задать отдельную колоду и язык каждому пользователю:
# TELEGRAM_USER_PROFILES=100000001:de:LearnerOne::German,100000001:en:LearnerOne::English,100000002:de:LearnerTwo::German,100000002:en:LearnerTwo::English,100000003:de:LearnerThree::German,100000003:en:LearnerThree::English,100000003:ko:LearnerThree::Korean
ANKI_NOTE_TYPE=German Context v1
POLZA_TEXT_MODEL=google/gemini-3.5-flash
POLZA_IMAGE_MODEL=google/gemini-2.5-flash-image
POLZA_TRANSCRIPTION_MODEL=openai/gpt-4o-mini-transcribe
FFMPEG_BIN=ffmpeg
VOICE_MAX_BYTES=25000000
APP_LOG_LEVEL=DEBUG
APP_LOG_FILE=logs/app.log
APP_LOG_FULL_DEBUG=true
```

Бот должен отвечать только пользователям из `ALLOWED_TELEGRAM_USER_IDS`. Для профилей из `TELEGRAM_USER_PROFILES` этот список строится автоматически. Формат профиля: `telegram_user_id:language:deck_name`, поддерживаются `de`, `en` и `ko`; несколько записей с одним ID задают несколько доступных языков. Команда `/language` меняет текущий язык и сохраняет его в SQLite. Каждый пользователь и язык имеют отдельную колоду; AnkiWeb-аккаунт при этом остаётся общим для семьи.

7. Установить зависимости:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .[dev]
```

8. Запустить Anki Desktop.
9. Запустить бота:

```powershell
anki-telegram-bot
```

## Логирование

Бот пишет диагностические логи в формате JSON lines в консоль и файл `logs/app.log`. Файл ротируется по настройкам:

```dotenv
APP_LOG_LEVEL=DEBUG
APP_LOG_FILE=logs/app.log
APP_LOG_MAX_BYTES=10485760
APP_LOG_BACKUP_COUNT=5
APP_LOG_FULL_DEBUG=true
```

При `APP_LOG_FULL_DEBUG=true` в логах сохраняются пользовательские тексты, prompts, ответы `polza.ai`, JSON черновиков и параметры внешних запросов. Это удобно для полной отладки, но такие логи могут содержать личные данные и содержимое карточек. Секреты вроде `TELEGRAM_BOT_TOKEN`, `POLZA_AI_API_KEY` и HTTP `Authorization` маскируются. Директория `logs/` уже исключена из git.

Image pipeline сразу запускает генерацию изображения через `polza.ai` и не тратит отдельные ИИ-запросы на подбор Wikimedia query или оценку найденных кандидатов. Ответ генерации изображения логируется до разбора структуры, а async-ответы с `requestId` проверяются через `GET /media/{id}` до completed/failed/timeout.

Для фото-сценария бот скачивает Telegram photo в `data/media`, отправляет изображение в `polza.ai` как vision input, создает карточку по главному объекту или действию и использует исходное фото как картинку карточки. Base64 payload изображения в логах маскируется.

Голосовой и аудио-сценарий временно выключен: handlers для Telegram voice, audio и MP3-document не регистрируются. Код скачивания, `ffmpeg`-конвертации, Polza STT `/audio/transcriptions`, сохранения MP3 в `UserAudio` и маскирования base64-аудио оставлен в проекте как заготовка для будущей переработки.

## Ожидаемый Сценарий

Пользователь отправляет:

```text
оформить страховку
```

Пользователь также может спросить, как сказать фразу в ситуации, например `Как сказать официанту "без сдачи"`; бот сохранит в карточке исходный смысл `без сдачи`, но использует контекст официанта для естественных немецких вариантов. Бот сначала показывает варианты значения. Если короткая подпись варианта отличается от немецкой цели карточки, бот показывает ее отдельной строкой, например `Карточка: eine Versicherung abschließen`. После выбора значения бот создает черновик:

```text
eine Versicherung abschließen
оформить / заключить страховку

Пример:
Ich möchte <b>eine Versicherung abschließen</b>.
Я хочу <b>оформить страховку</b>.

Значение: заключить договор страхования

Частотность: medium
```

К черновику прикрепляется картинка. Перед сохранением доступны кнопки:

Если пользователь отправляет голосовое сообщение или MP3-аудиофайл, текущая версия не запускает создание карточки по аудио. Этот сценарий будет переработан позже.

- `Добавить`;
- `Исправить`;
- `Другая картинка`;
- `Отмена`.

## AI-Исправление

После кнопки `Исправить` пользователь отправляет сообщение:

```text
сделай пример про рабочую ситуацию и уточни перевод как "оформить страховку"
```

Бот отправляет полную карточку и инструкцию в `polza.ai`, получает обновленный JSON карточки, снова проверяет обязательную грамматику и показывает новый preview. Текущая картинка при AI-исправлении остается прежней; для замены есть кнопка `Другая картинка`.

## Критерии Готовности

- Черновик сохраняется в SQLite и доступен после перезапуска.
- Перед генерацией черновика пользователь выбирает конкретное значение из 1-5 вариантов.
- Черновик заполняет формат `German Context v1`, описанный в [ANKI_CARD_FORMAT.md](ANKI_CARD_FORMAT.md).
- Частотность и исходный пользовательский ввод сохраняются в отдельных полях Anki.
- Картинка появляется у каждой карточки; для фото-сценария используется исходное Telegram-фото.
- Аудио-сценарий сейчас не должен запускаться при отправке voice/audio/MP3 в Telegram.
- Если пользователь не прислал фото, запускается генерация изображения через `polza.ai`.
- Карточка добавляется в выбранную колоду Anki.
- Изображение попадает в Anki media.
- После `addNote` бот вызывает AnkiConnect `syncAndWait`, чтобы отправить изменения в AnkiWeb и дождаться завершения collection sync. Если sync падает, карточка не добавляется повторно; ошибка пишется в `logs/app.log`.
- Стоимость всех относящихся к карточке запросов Polza суммируется по `usage.cost_rub` и сохраняется в черновике. Финальное сообщение показывает точную сумму, известную нижнюю границу или недоступность цены.
- Кнопка `Отмена` не добавляет карточку в Anki.

## Live-Проверка

1. Проверить, что `.env` содержит реальные `TELEGRAM_BOT_TOKEN`, `POLZA_AI_API_KEY` и `ALLOWED_TELEGRAM_USER_IDS`.
2. Запустить Anki Desktop с установленным AnkiConnect.
3. Запустить `anki-telegram-bot`.
4. Отправить боту `оформить страховку`.
5. Выбрать конкретное значение inline-кнопкой.
6. Проверить, что бот показывает полный preview и картинку.
7. Нажать `Исправить` и отправить свободную инструкцию.
8. Нажать `Добавить` и проверить карточку в Anki.
9. Убедиться, что используется note type `German Context v1`, изображение открылось в Anki и черновик не остался в состоянии ошибки.
